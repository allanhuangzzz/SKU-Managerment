# 产品SKU管理系统 · 群晖 NAS 部署说明（Docker / Container Manager）

> 代码唯一来源是仓库根目录（GitHub），NAS 上只保留本部署目录（compose 文件 + 数据），不存放代码副本。
> 更新链路：本地改完 `git push` → GitHub Actions 自动构建并推送 GHCR / Docker Hub → NAS 拉新镜像重启。

## 一、目录结构

```
deploy_nas/                 # 部署目录（Container Manager「项目」选择的路径）
├── docker-compose.yml      # ★ 两个服务：sku（应用）+ watchtower（更新执行器）
├── Dockerfile              # 供 GitHub Actions 构建使用，NAS 上无需本地构建
├── requirements.txt
├── .dockerignore
└── data/                   # ★ 数据目录（必须保留）
    ├── sku.db              # SQLite 数据库（全部业务数据）
    └── uploads/            # 产品图片
```

## 二、首次部署

前置：套件中心安装 **Container Manager**（旧版叫 Docker）。

1. 把整个 `deploy_nas` 目录（含 `data/`）通过 File Station 传到 NAS，
   例如 `/volume1/docker/sku`（路径尽量不含中文）。
2. Container Manager → **项目** → **新增** → 路径选该文件夹 → 使用现有 `docker-compose.yml` →
   构建并启动。会自动拉取两个镜像：应用镜像与 watchtower。
3. 浏览器打开 `http://NAS的IP:5050`（NAS IP 在 控制面板 → 网络 → 网络界面 查看）。

> 端口默认 `5050`（DSM 占用 5000/5001）。想换端口改 `docker-compose.yml` 里 `"5050:5050"` 左边数字后重建项目。

## 三、日常更新（三种方式任选）

**1. 面板一键更新（推荐）**

应用左下角有「当前版本」与「一键更新」按钮，点击后：

- 有新版本 → 自动拉取镜像并重建容器，页面提示 `更新完成：旧版本 → 新版本`，点「刷新页面」即可；
- 已是最新 → 提示「已是最新版本，无需更新」，服务不会重启；
- 更新期间页面会短暂无法访问（几秒），属正常现象。

原理：按钮请求 watchtower 的 HTTP API（`http://watchtower:8080/v1/update`），
由 watchtower 拉取最新镜像并重建 sku 容器。

**2. 群晖图形界面**

「映像」→ 找到 `allanhuangzzz/sku-managerment:latest` → 更新 → 回到「项目」→ 构建（或停止后再启动）。
注意：Compose 不会自动重新拉取 `latest`，所以要先更新映像再重建，否则仍会用本地旧映像。

**3. SSH 命令行**

```bash
cd /volume1/docker/sku
sudo docker compose pull
sudo docker compose up -d
```

### 关于 watchtower

- **不轮询、不自动更新**：只在面板点按钮时工作，平时不产生流量与 CPU 占用；
- 需要挂载 `/var/run/docker.sock`（compose 已配置），这是它能执行更新的前提；
- 只更新带 `com.centurylinklabs.watchtower.enable=true` 标签的容器（即 sku 自身）；
- 更新成功后自动删除旧镜像（`WATCHTOWER_CLEANUP`），避免占用 NAS 空间。

### 可选：修改更新口令

面板按钮与 watchtower 之间用一个口令校验。默认口令写在 compose 里，
如需改成自己的，在本目录新建 `.env`：

```
UPDATE_TOKEN=你的口令
```

然后重建项目即可（`.env` 不会提交到仓库）。

## 四、数据说明与备份

- 全部数据在宿主机 `deploy_nas/data/`：数据库 `sku.db`，图片 `uploads/`。
  容器内对应 `/app/sku.db`、`/app/static/uploads`（compose 已挂载），
  **容器重建、更新、删除都不会丢数据**。
- **备份**：定期复制 `data/` 目录即可。建议在群晖「Hyper Backup」中把该目录加为备份源。
- 电脑与 NAS 之间同步数据：停容器 → 拷贝 `sku.db` 与新增图片进 `data/` → 再启动。

## 五、离线 / 内网使用提示

- 应用启动时会尝试联网刷新实时汇率（主备两个免费接口），**失败不影响运行**，
  会自动使用数据库内已有汇率（也可在「汇率维护」页手动修改）。
- 「一键更新」需要 NAS 能访问 Docker Hub（拉取镜像）。若 NAS 无法上外网，
  该按钮会提示触发失败，此时请改用离线方式更新（把新镜像导入 NAS 后再重建容器）。
