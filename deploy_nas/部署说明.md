# 产品SKU管理系统 · 群晖 NAS 部署说明（Docker / Container Manager）

> 本目录是独立部署包，代码已适配 NAS（监听 0.0.0.0、端口 5050、不自动开浏览器），
> 原项目目录未做任何改动。数据（`sku.db` + 产品图片）已连同最近一次更新一并放入 `data/`。

## 一、目录结构

```
deploy_nas/
├── app.py                # 已适配：HOST=0.0.0.0，PORT 默认 5050（可用环境变量覆盖）
├── db.py
├── import_shipping.py    # 运费模板导入（可选使用）
├── requirements.txt      # 依赖：flask
├── Dockerfile            # 构建映像
├── docker-compose.yml    # 一键启动 + 数据持久化
├── .dockerignore
├── templates/ static/    # 前端页面与资源
└── data/                 # ★ 数据目录（NAS 上的持久化位置）
    ├── sku.db            # SQLite 数据库（全部业务数据）
    └── uploads/          # 产品图片
```

## 二、在群晖上部署（推荐 Docker）

前置：套件中心安装 **Container Manager**（旧版叫 Docker）。

1. **上传**：把整个 `deploy_nas` 文件夹通过 File Station 传到 NAS 的共享目录，
   例如 `/volume1/sku/deploy_nas`（路径里最好不含中文，避免兼容问题）。
2. **构建并启动**（两种方式任选）：

   - 方式 1（SSH 命令行）：
     ```bash
     cd /volume1/sku/deploy_nas
     docker compose up -d --build
     ```
   - 方式 2（Container Manager 图形界面）：
     - 项目 → 选中该文件夹 → 构建映像（Dockerfile 已就绪）；
     - 在「容器」中点击「运行」→ 端口映射 5050→5050、勾选「启用自动重新启动」。

3. **访问**：浏览器打开 `http://NAS的IP:5050`（NAS IP 在 控制面板→网络→网络界面 查看）。
   同一局域网内手机/其他电脑输入同一地址即可访问。

## 三、数据说明与备份

- 全部数据在宿主机 `deploy_nas/data/`：数据库 `sku.db`，图片 `uploads/`。
  容器内对应 `/app/sku.db`、`/app/static/uploads`（docker-compose 已做挂载），
  **容器删除/升级不会丢数据**。
- **备份**：只需定期复制 `data/` 目录。建议在群晖「Hyper Backup」中把该目录加为备份源，
  或复制到另外的位置（本次迁移前务必保留原电脑上的源文件作为兜底）。
- 以后要同步电脑上的新数据：停容器 → 把电脑的 `sku.db` 和新增图片拷入 NAS 的 `data/` → 再启动。

## 四、更新部署包 / 换端口

- 端口：编辑 `docker-compose.yml` 中 `"5050:5050"` 左边数字，然后 `docker compose up -d` 重建即可。
- 更新代码：在源项目改完后，把对应文件（app.py/db.py/static/templates…）复制进本目录，重新
  `docker compose up -d --build`；`data/` 不用动。

## 五、离线内网使用提示

- 启动时应用会尝试联网刷新实时汇率（主备两个免费接口），**失败不影响运行**，
  会自动使用数据库内已有汇率（也可在页面「汇率维护」中手动修改）。
- 如 NAS 无法上外网，属正常降级，无需额外配置。
